# Project Rules & Scope

## 1. Working Scope
- **Active Codebase:** All development, code changes, refactoring, and file modifications must strictly occur within `Volunteer_FE`.
- **Backend Directory (`Volunteer_BE` / `Volunteer_BE-master`):** **Read-only**.
  - Only consult the backend folder for reference purposes (e.g., inspecting GraphQL/REST schemas, DTOs, domain models, entity definitions, and business logic).
  - **Never** modify, create, or delete any files in the backend folder.
